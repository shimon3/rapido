# Security policy

Report vulnerabilities privately through GitHub's **Report a vulnerability**
form (https://github.com/shimon3/rapido/security/advisories/new). If that form
is unavailable, contact Samuel Bentouza privately. Never open a public issue
for a security problem.

Known, documented limitation: Rapido does not protect against a program that
already runs under the same Windows account (issue #26). Reports that improve
this boundary are welcome. A report that only restates it will be linked to #26.

Supported versions: only the latest beta build distributed by the maintainer.
Unsigned beta builds are identified by their SHA-256 hashes and source commit.
